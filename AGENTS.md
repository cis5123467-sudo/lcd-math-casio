# LCD Math project instructions

## Release filenames

Chris requests all future releases use `lcd-math-v0.0.1.g3a`, then `lcd-math-v0.0.2.g3a`, `lcd-math-v0.0.3.g3a`, and so on, incrementing the patch number for each release. The latest release is `lcd-math-v0.0.1.g3a`; the next new release is `lcd-math-v0.0.2.g3a`. Legacy 1.0.x binaries remain preserved. Do not continue the old 1.0.x numbering. Do not replace existing release binaries. Match the new filename version in G3A metadata, build output, checksums, documentation and verification scripts when preparing that release.

## Interface

Use Chris's physical fx-85GT CW photo as the appearance reference. Keep contrast adjustable and persistent. The main calculation screen must contain only the expression, result and normal calculator status indicators, with no branding, shortcut bar, tooltips or help text.
